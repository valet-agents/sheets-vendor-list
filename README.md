# Sheets Vendor List

Tracks approvals, expirations, and renewal windows — pings owners 60 days out so nothing lapses unnoticed.

## Prerequisites
- A Google account with access to the vendor list spreadsheet (you'll OAuth into Google Sheets)
- A Slack workspace where you can install the agent's bot and invite it to one or more channels
